# Face-Attendance-system
Face Recognition Attendance System (Python & Laravel API)

Developed a real-time face recognition system using Python, OpenCV, and face_recognition library.

Integrated with a Laravel API to log user attendance (in/out) dynamically.

Implemented single-entry per detection with a timeout-based mechanism, ensuring accurate logging even with long-running cameras.

Handled multiple users, real-time detection, and API integration for automated attendance tracking.

Optimized system to prevent duplicate entries and manage user presence intelligently.

Technologies: Python, OpenCV, face_recognition, NumPy, Laravel API, RESTful integration, real-time computer vision.
